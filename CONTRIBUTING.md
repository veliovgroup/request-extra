# Contributing

Search [existing issues](https://github.com/veliovgroup/request-extra/issues) before opening a new one. Keep reports limited to `request-libcurl`.

Include:

- `request-libcurl` package version
- Node.js version
- Operating system and architecture
- Minimal reproduction
- Expected behavior
- Actual behavior
- Complete error output

Pull requests are welcome at [compare](https://github.com/veliovgroup/request-extra/compare). Explain behavior change, update relevant docs, and include tests when code changes.
